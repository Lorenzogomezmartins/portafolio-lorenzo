Landing Page · Fuego Burgers

Diseño moderno y modular para marca gastronómica

Descripción General

Landing page desarrollada para una hamburguesería urbana con identidad visual fuerte y moderna. El proyecto está construido con arquitectura modular mediante carga dinámica de componentes, scroll animado personalizado y diseño completamente responsive.

Tecnologías Utilizadas

HTML
CSS
JavaScript
Fetch API
Bootstrap

Funcionalidades Principales

  • Navbar fijo con animación de subrayado.
  • Scroll suave con ajuste dinámico por altura del header.
  • Carga modular de secciones (partials).
  • Carrusel interactivo en sección novedades.
  • Diseño responsive adaptable a distintos dispositivos.
  • Botón flotante de WhatsApp.

Secciones de la Landing

  • Hero principal con imagen impactante.
  • Sección de novedades con promociones destacadas.
  • Menú visual organizado.
  • Contacto con redes sociales.
  • Footer institucional.

Experiencia de Usuario

  • Navegación fluida y moderna.
  • Animaciones suaves y transiciones elegantes.
  • Diseño minimalista con enfoque visual fuerte.
  • Estructura escalable para futuros desarrollos.

Qué Demuestra Este Proyecto

  • Organización modular profesional.
  • Manejo de JavaScript para manipulación del DOM.
  • Aplicación de diseño moderno orientado a marca.
  • Buenas prácticas en estructura y separación de archivos.
