Sala de Juegos · Aplicación Web Interactiva

Trabajo Práctico N°1 · Programación IV · UTN Avellaneda

Descripción General

Sala de Juegos es una aplicación web desarrollada en Angular como Trabajo Práctico N°1 para la materia Programación IV de la UTN Avellaneda. Incluye autenticación, navegación protegida, juegos interactivos, chat en tiempo real, resultados y estadísticas conectadas a Supabase.

Tecnologías Utilizadas

Angular
TypeScript
HTML
CSS
Supabase
Bootstrap

Funcionalidades Principales

  • Registro e inicio de sesión con Supabase.
  • Persistencia de usuarios en base de datos.
  • Guards para proteger rutas privadas.
  • Home dinámico según el usuario logueado.
  • Chat en tiempo real con usuario, fecha y diferenciación de mensajes propios.
  • Resultados guardados en Supabase.
  • Tablas de resultados ordenadas por puntaje.
  • Diseño responsive con animaciones y modales personalizados.

Juegos Incluidos

  • Ahorcado: juego clásico de adivinar palabras.
  • Mayor o Menor: juego de predicción de cartas.
  • Preguntados: juego de preguntas utilizando una API externa.
  • Ruleta Casino: juego propio con sistema de fichas y apuestas.

Juego Propio · Ruleta Casino

El jugador comienza con 100 fichas y puede apostar a rojo/negro, par/impar o a un número específico. La ruleta genera un número aleatorio entre 0 y 36. El objetivo es llegar a 250 fichas antes de quedarse sin saldo.

  • Ganar: llegar a 250 fichas.
  • Perder: quedarse sin fichas.
  • Apuestas: rojo/negro, par/impar y número específico.
